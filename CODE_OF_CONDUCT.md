# Code de conduite

## Notre engagement

Ce projet veut rester un endroit accueillant pour tout le monde, quel que soit le niveau, la langue,
l'origine, l'identité ou l'expérience. Les contributions, questions et critiques techniques sont
bienvenues ; les comportements méprisants ne le sont pas.

## Ce qui est attendu

- Rester courtois et factuel : critique le code, pas la personne.
- Accepter les retours et expliquer ses choix ("pourquoi", pas seulement "ce n'est pas bien").
- Respecter le fait que le projet vise un usage précis (webcam USB iPhone → Windows, sans audio) :
  une proposition hors périmètre n'est pas un affront, elle est simplement discutée d'abord.
- Ne pas publier d'informations privées (les tiennes ou celles d'autrui), y compris dans les journaux
  de diagnostic.

## Ce qui ne l'est pas

- Insultes, harcèlement, propos discriminatoires ou désobligeants.
- Trollage, provocations répétées, remise en cause personnelle des mainteneurs.
- Publication d'informations privées ou de vulnérabilités non corrigées.

## Portée et application

Ce code s'applique aux issues, pull requests, discussions et à tout espace lié au projet. En cas de
manquement, la modération peut supprimer un message, fermer un fil et, si nécessaire, bloquer un
compte. Pour signaler un problème, écris à **allan1411lannoy@gmail.com** : les signalements sont traités
discrètement et le signalant n'est pas exposé.

Ce texte s'inspire du [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
dont la version anglaise fait foi en cas de doute.
